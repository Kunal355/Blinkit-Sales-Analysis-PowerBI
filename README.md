# Blinkit-Sales-Analysis-PowerBI
Project Overview

🚀 Blinkit Sales Analysis - Power BI Dashboard

A Power BI project analyzing Blinkit’s sales data to uncover trends in revenue, customer behavior, and product performance. Features interactive dashboards with geospatial mapping, time intelligence, and product/category insights—helping optimize inventory, marketing, and delivery operations.

Key Insights

✔️ Top-selling products & peak order times 
✔️ Regional sales hotspots
✔️ YoY/MoM growth trends
✔️ Customer purchase patterns
